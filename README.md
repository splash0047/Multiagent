## Overview

**KEEP v3** is a production-grade, highly scalable multi-agent research engine. It transitions the original KEEP v2 synchronous prototype into a robust enterprise platform designed to perform exhaustive, deterministic, hallucination-free citation research. 

Every claim generated by KEEP is grounded and verified. The system orchestrates a swarm of specialized AI agents to plan research strategies, gather data from external search APIs and internal proprietary documents (RAG), validate sources, extract facts, synthesize final reports, and rigorously verify citations.

## Key Features & Upgrades

- **Hybrid Cost-Routing (Cloud + Local LLMs):** Dynamically assigns complex reasoning tasks (Planning, Synthesis) to high-tier cloud models (Google Gemini 2.5 Flash / GPT-4o) and routes repetitive classification/extraction tasks to high-efficiency local models via Ollama (Llama-3-8B / Gemma-2-9B). Reduces API costs while maintaining top-tier reasoning.
- **Private Document Ingestion (RAG):** Allows users to securely ingest proprietary data (PDFs, DOCX, CSV) and research them alongside public web data via a `LocalDocumentTool`.
- **Persistent Vector Memory:** Uses Pinecone Serverless Integrated Inference to prevent redundant extraction, skip repeated searches, and grant the system "long-term memory" across sessions.
- **Multi-Modal Output:** Includes a Data Visualization agent capable of generating matplotlib/seaborn charts based on extracted tables. Exports final research reports cleanly to Markdown or PDF.
- **Real-Time Streaming SaaS UI:** Features a Next.js (TypeScript) frontend connected to a FastAPI backend with real-time SSE streaming for animated agent status, interactive trace timelines, and LLM Cost-Routing analytics.

## Architecture

![Current system architecture](docs/architecture/architecture.svg)

[Download the interactive Archify diagram (open locally)](docs/architecture/architecture.html) · [View the source specification](docs/architecture/architecture.json)

This diagram maps the components present in the repository. Optional integrations and implementation limits are called out in the diagram.

The system is powered by LangGraph, enforcing rigorous state transitions and Pydantic schema validation at each step:

1. **Planner Agent:** Analyzes the query, decides if it requires web search, private document search, or hybrid search, and creates a plan.
2. **Search Agent / Document Tool:** Retrieves relevant sources from Tavily/Arxiv or Pinecone vector DB.
3. **Validator Agent:** Ranks, scores, and filters sources based on credibility before data extraction.
4. **Extractor Agent:** Chunks documents and extracts verifiable, isolated claims.
5. **Synthesizer Agent:** Weaves isolated claims into a coherent research narrative.
6. **Citation Verifier:** Cross-checks the synthesized report against original URLs and document chunks to prevent hallucination.
7. **Confidence Engine:** Calculates a mathematical confidence score based on the number of validated sources, claim density, and successful verification rates.

## Setup & Installation

### Prerequisites
- Python 3.10+
- Node.js 18+ (for Next.js Frontend)
- [Ollama](https://ollama.com/) (installed locally if using Hybrid Cost-Routing)

### Backend Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/splash0047/Multiagent.git
   cd Multiagent/KEEP_v2
   ```

2. **Install Python dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Configure Environment Variables:**
   Copy `.env.example` to `.env` and fill in your API keys (Gemini, Tavily, Pinecone, etc.).
   ```bash
   cp .env.example .env
   ```

4. **Start Local LLMs (Optional but Recommended):**
   ```bash
   ollama run llama3
   ```

5. **Run the FastAPI Backend:**
   ```bash
   python -m uvicorn src.api:app --reload --port 8000
   ```
   *(Alternatively, run the legacy Streamlit MVP UI: `streamlit run app.py`)*

### Frontend Setup (Next.js SaaS UI)

1. **Navigate to the frontend directory:**
   ```bash
   cd frontend
   ```

2. **Install Node dependencies:**
   ```bash
   npm install
   ```

3. **Run the Development Server:**
   ```bash
   npm run dev
   ```

## Usage

1. Open the UI in your browser (usually `http://localhost:3000` for Next.js or `http://localhost:8501` for Streamlit).
2. Enter a research query in the search bar.
3. Watch the real-time agent trace timeline as KEEP plans, searches, extracts, and validates.
4. Review the final report, click on the inline citations to view original sources, and check the Cost-Routing metrics to see the breakdown of Cloud vs Local LLM usage.
5. Export the report to PDF or Markdown.

## Observability & Metrics

KEEP provides advanced observability:
- **Trace Replay:** Step-by-step logs of every agent action and API response.
- **Cost Savings Analytics:** Real-time calculation of money saved by using local Ollama models for classification tasks vs using an all-cloud approach.
- **Latency Tracking:** End-to-end timing breakdown per pipeline step.
